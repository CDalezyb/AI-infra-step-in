# BatchNorm、LayerNorm 和 RMSNorm 的区别

| 特性         | BatchNorm                         | LayerNorm                        | RMSNorm                          |
|--------------|-----------------------------------|----------------------------------|----------------------------------|
| 归一化维度   | Batch 维度（B）                   | 特征维度（C 或 D）               | 特征维度（C 或 D）               |
| 依赖 Batch 大小 | 是                                | 否                               | 否                               |
| 适用场景     | 卷积网络、批量较大                | RNN、Transformer、小批量         | Transformer、NLP                 |
| 计算方式     | 均值和方差                        | 均值和方差                       | 仅均方根（不减均值）             |
| 额外参数     | γ（缩放）、β（偏移）              | γ、β                             | γ（可选）、无偏移                |
| 训练/推理差异 | 需要维护滑动均值                  | 无差异                           | 无差异                           |

## 简要说明

- **BatchNorm**：对每个特征在 batch 维度上归一化，依赖 batch 统计量，适合卷积网络。
- **LayerNorm**：对每个样本的特征维度归一化，独立于 batch，适合序列建模。
- **RMSNorm**：仅用均方根归一化，不减均值，参数更少，常用于 Transformer。
